# Currency_converter
A simple and interactive Currency Converter built using HTML, CSS, and JavaScript.  I made this project while practicing JavaScript and working with an API to get currency exchange rates. You can select two currencies, enter an amount, and get the converted value instantly.

About the Project

The idea was pretty simple: make a small currency converter that is easy to use and gives the user the converted amount without needing to calculate it manually.

The project helped me understand how JavaScript can work with external APIs and use the received data to update a webpage dynamically.

✨ Features
💱 Convert one currency into another
🌎 Multiple currencies to choose from
🔄 Select both source and target currencies
💰 Enter any amount to convert
⚡ Get the converted amount dynamically
🎨 Simple and user-friendly interface
🛠️ Technologies Used
HTML5 — Structure of the webpage
CSS3 — Styling and layout
JavaScript — Conversion logic and DOM manipulation
Currency Exchange API — Fetching exchange-rate data
🧠 How It Works
Select the currency you want to convert from.
Select the currency you want to convert to.
Enter the amount.
JavaScript sends a request to the currency API.
The exchange rate is received from the API.
The amount is multiplied by the exchange rate.
The converted amount is displayed on the screen.

For example:

100 USD → EUR

The app gets the current exchange rate and calculates the equivalent amount in EUR.

Exchange rates can change over time, so the result depends on the rate provided by the API.
